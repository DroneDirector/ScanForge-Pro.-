# ScanForge Pro 1.0.0 (alpha)

First test version for Android phones (ARM64).

## What it does
- **Scan with camera**: walk around an object; the ring shows which sides are covered. Turn on *Auto* to take photos automatically at each new angle.
- **Import photos** from a camera or drone.
- **Build 3D model** on the phone (Fast / Normal / High / Ultra).
- **View** the model in colour or as plain shape.
- **Size**: enter one real measurement in mm.
- **Flat base**: the table is removed automatically; adjust the cut if needed.
- **Export** STL or 3MF for Bambu Studio / Bambu Handy, or PLY / OBJ with colours.

## Tips
Use 30–80 photos, with a second round from higher up. Matt, textured objects scan best; place plain objects on a newspaper or patterned cloth.

## Known limits
- Processing on a phone takes minutes; keep the app open.
- Shiny, transparent and single-colour objects may fail.
- This alpha is signed with a test key; the Play Store version will use a different key (uninstall first then).
