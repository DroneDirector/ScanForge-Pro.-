# ScanForge Pro 1.0.2 (alpha)

## New
- **In-app updates**: when a new version is published, the app tells you at start-up, shows what's new, downloads it with a progress bar and opens the Android installer. You can also choose *Later* or *Skip this version*.
- **Your scans and settings are kept** when updating.
- **Settings screen** (gear icon on the home screen):
  - Check for updates automatically (on/off) and *Check now*
  - Default quality and default printer for new scans
  - About and credits

## First update
The first time, Android asks you to allow ScanForge Pro to install apps. Allow it once, go back, and tap *Install*.

This version must be installed manually one last time. From now on, updates come through the app.
