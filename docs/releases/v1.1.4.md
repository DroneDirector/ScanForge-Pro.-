# ScanForge Pro 1.1.4 (alpha)

## Live Scan waits for the object
- **No photos until the object is recognised.** Live Scan starts taking photos only after you've tapped the object and its hologram dots are showing on it.
- **Dots appear right after tapping**, shaped from the AI outline, so you can see the object was recognised before scanning starts.
- **No automatic picking:** the app never guesses the object for you.
- While it recognises the object the hint says *Recognising the object… hold the phone still*. If it can't see the shape, it tells you to move a bit closer or tap *Reselect*.

Update from inside the app; your scans and settings are kept.
